# Sunny Login Page

A single-screen React login page built with Create React App. The layout centers a login card with an elevated form, inline validation, and responsive interactions so you can showcase credential collection without wiring up a backend.

## Getting started

```bash
cd frontend
npm install
npm start
```

## Features

- Centered login card with subtle gradients and depth
- Email/password validation with inline error messaging
- Disabled submit button while the fake authentication runs
- Accessible labels, focus styles, and auxiliary navigation links
